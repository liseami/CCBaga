mod.rs: 当前/空/已保存身份与切换/恢复/重命名/直接删除 Tauri 命令，复用 Cleaner 全局事务锁；UI 接收目录元数据及显式允许的本地账号显示字段；令牌不送 UI。
database.rs: 内嵌 SQLite 管理身份目录、用户保留策略及切换恢复状态；FULL 同步与数据库事务，凭据正文不入库。
store.rs: 压缩加密归档、SQLite 协调的切换/失败恢复与明确的无新增备份删除；归档绑定平台、用户目录和本机保险库密钥，不声称抵抗用户自行复制全部密钥与数据。
profile.rs: 只读默认 .claude.json 的用户名/邮箱/组织显示白名单，API Key 仅记存在性、桌面仅检查身份路径元数据；不可读不冒充空身份，不读取钥匙串或 Cookie 正文。
credentials.rs: 默认 Code 凭据按用户策略合并身份与共享 MCP/插件秘密；正文只在原生内存流动。
codec.rs: tar/gzip 流与 ring AES-256-GCM 帧，独立归档密钥和认证结尾；拒绝篡改、截断与非法归档成员。
private.rs: POSIX 0700/0600 与 Windows 创建时指定当前用户所有者/独占 DACL、原子写入；拒绝所有者变化、链接和特殊文件。
tests.rs: 临时账号/会话样本的空身份、恢复、配置保留、损坏与链接拒绝和未完成事务恢复、选择性永久删除与跨策略恢复、缺失主密钥拒绝，使用同一私有创建层模拟管理员文件所有者，不接触真实账号。
