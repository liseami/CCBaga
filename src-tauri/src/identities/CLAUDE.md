mod.rs: 当前/空/已保存身份与停止/原地备份/切换/恢复/重命名/删除 Tauri 命令，复用 Cleaner 全局事务锁；普通刷新仅读 SQLite 和本地显示元数据，不打开 Store、不解密归档或回填摘要；进程预览至多 32 项，失败为 null 且停止状态保守未知；UI 不接收凭据正文。
database.rs: 默认开启联动且保留显式关闭，SQLite v3 管理稳定槽位、不可变归档代次、HMAC 索引与持久恢复状态；脱敏摘要读时重算本地过期状态，旧摘要未知；原地备份同事务提交档案/名称/摘要；迁移严格新增身份/摘要/可选绑定并拒绝已存账号，均不改选择指针，凭据正文不入库。
store.rs: 原地加密备份只提交档案、不切换浏览器或清工作区；先验收归档再切换、失败回滚、独立恢复检查点与显式删除；迁移打开方式拒绝 recovery 且不回收旧暂存/归档或解包建索引；旧归档瞬态锁不恢复，非空同名目录按用户策略保留，清除/恢复按真实源计数，关键阶段及每 250ms 复查进程。
profile.rs: 只读显示白名单与本地凭据订阅/过期元数据，已认证归档生成脱敏摘要；状态只表示 local_unexpired/expired/refresh_available/api_key/unknown，不联网、不承诺自动续期，未知过期时间及旧摘要降级未知；API-only 设置仍是身份；只展示真实进程名/PID，不从可能复用 PID 的旧会话文件猜测工作区，不打开系统钥匙串或 Cookie。
credentials.rs: 默认 Code 凭据按用户策略合并身份与共享 MCP/插件秘密；正文只在原生内存流动。
archive.rs: 新身份复用空浏览器预留编号；新快照排除固定锁的普通文件/空目录与精确默认 debug/latest 链接，不跟随或删除原件；通用迁移/恢复遍历仍拒绝全部链接；tar/Zstd 与旧 gzip 兼容验收，代次与卡片编号分离，源文件/压缩认证落盘/完整解包验收分阶段报告，完整认证后才交目录事务。
catalog.rs: 有界读取账号 UUID/组织（缺失时邮箱/组织），以本机 HMAC 匹配稳定槽位；显式事务打开 Store 时仅为缺账号索引的旧副本验收建索引，缺摘要不强制解密；归档回收仅接受本次提交（含已完成回滚）已知且不再被引用的候选，打开保险库不凭缺少索引删除完整归档；未知账号与恢复检查点不猜测合并，Desktop-only 暂存保守保留。
compression.rs: Zstandard 级别 3 流式压缩与校验和，读取侧限制窗口并按魔数兼容旧 gzip；外层认证协议不变。
optimization_tests.rs: 共享虚构账号夹具、A/B 连续切换、原地备份不动工作区与浏览器指针、缺摘要惰性保留、空身份往返、仓库路径/代理和跨应用不同账号资产保留、三平台路径契约、凭据刷新、跨组织隔离、崩溃恢复及压缩认证兼容；手动 500 会话性能样本不设 CI 时间阈值。
backup_tests.rs: 临时 A 浏览器/B CLI 备份保留真实不匹配、摘要失败事务回滚、旧归档锁不恢复而非空同名目录不丢数据；内嵌 SHA 固定的 v0.2.48 zstd 0.13.3 三平台合成 v1 tar，由当前 0.14.2 解包并只重定位到夹具执行恢复；不访问真实来源、进程或钥匙串。
codec.rs: 压缩流与 ring AES-256-GCM 帧，独立归档密钥和认证结尾；拒绝篡改、截断与非法归档成员。
