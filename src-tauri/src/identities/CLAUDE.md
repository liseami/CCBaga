mod.rs: 当前/空/已保存身份（刷新只读工作区，仅在旧归档缺失索引或摘要时持锁回填一次）、无需目录扫描的进程停止与原地备份/切换/恢复/重命名/直接删除 Tauri 命令，复用 Cleaner 全局事务锁；进程停止通道可选且报告开始/真实完成/失败，兼容旧调用；UI 只接收目录、脱敏摘要、活跃会话和允许的账号显示字段。
database.rs: 默认开启联动且保留显式关闭，SQLite v3 管理稳定账号槽位、不可变归档代次、脱敏身份摘要表（identity_summaries）、HMAC 索引、互斥提交后的空身份临时记录回收与持久恢复状态；旧 v1/v2 事务迁移，覆盖指针与恢复标记同事务提交，凭据正文不入库。
store.rs: 原地加密备份（save_current）、先验收归档再切换工作区、失败回滚、独立恢复检查点、锁文件清理与无新增备份删除；清除/恢复按完成源数量报告局部进度，凭据/提交/回滚显式阶段；关键阶段强制核验进程，文件循环每 250ms 复查。
profile.rs: 只读默认 .claude.json 与本地凭据元数据的用户名/邮箱/组织、订阅档位（Pro/Max 5x/Max 20x/Team/Enterprise/API）与离线凭据状态白名单、已暂存归档摘要提取及活跃会话工作区映射；API Key 仅记存在性、桌面仅检查身份路径元数据；不可读不冒充空身份，不读取钥匙串或 Cookie 正文。
credentials.rs: 默认 Code 凭据按用户策略合并身份与共享 MCP/插件秘密；正文只在原生内存流动。
archive.rs: 新身份复用空浏览器预留编号；tar/Zstd 与旧 gzip 兼容验收，代次与卡片编号分离；源文件写完后才递增完成数，压缩/认证落盘和完整解包验收分阶段报告；完整认证后才交目录事务，解包区可丢弃，归档本体保持 fsync。
catalog.rs: 有界读取账号 UUID/组织（缺失时邮箱/组织），以本机 HMAC 匹配稳定槽位；旧副本验收后索引并自动回填脱敏摘要，提交后去重/回收；未知账号与恢复检查点不猜测合并，Desktop-only 暂存保守保留。
compression.rs: Zstandard 级别 3 流式压缩与校验和，读取侧限制窗口并按魔数兼容旧 gzip；外层认证协议不变。
optimization_tests.rs: 虚构 A/B 连续切换、原地加密备份、旧归档摘要回填、互斥锁清理、空身份往返无泄漏、仓库路径隔离、保留代理与跨应用不同账号资料、macOS/Windows Desktop 范围及 Linux 排除 macOS 路径、凭据刷新、跨组织隔离、覆盖崩溃恢复、压缩兼容与认证尾部拒绝；手动 500 会话性能样本不设不稳定的 CI 时间阈值。
codec.rs: 压缩流与 ring AES-256-GCM 帧，独立归档密钥和认证结尾；拒绝篡改、截断与非法归档成员。
private.rs: POSIX 0700/0600 与 Windows 创建时指定当前用户所有者/独占 DACL、原子写入；已有目录仅校验，不改写父级权限；Win32 名称调用统一走长路径。
tests.rs: 临时账号/会话的空身份、恢复、配置保留、损坏/链接拒绝、选择删除、跨策略恢复与缺失主密钥拒绝；验证真实阶段与回滚，覆盖默认文件所有者、父级权限保留及不依赖 TEMP 长度的 Windows 超长路径往返，不接触真实账号。
browser_link.rs: 回环页有界身份摘要、绑定不匹配/未知状态且无凭据输出；SQLite 身份到独占浏览器资料的绑定、身份 ID 派生非零种子与碰撞登记；选择指针随切换/回滚同事务提交，旧卡合并保留当前资料。
browser_link_tests.rs: 默认勾选/显式关闭保留与身份摘要无令牌/不冒充网站账号；临时目录验证 A/B 复用、空资料轮换、迁移、种子碰撞与数据库拒绝不提交；无真实账号。
