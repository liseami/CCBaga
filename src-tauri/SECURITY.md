# 原生安全边界

此地图覆盖原生进程识别、清理路径、浏览器启动、系统设置、安装与代理传输。仓库中的原生宿主没有遥测、账号资料上传、剪贴板读取、浏览记录采集或远程凭据提取服务。身份管理经用户主动确认读取默认 Claude 凭据到受保护的本机加密保险库；不发送给 WebView 或网络。第三方浏览器、访问网站、AI 服务和外部安装器的行为不属于这一实现边界。

## 数据流

| 边界 | 读取与输出 | 限制与依据 |
| --- | --- | --- |
| `src/linux.rs` | 当前用户 `/proc` 的进程可执行路径/参数；系统时区、CPU、会话语言和桌面定位偏好 | 参数只用于原生识别，不序列化给 WebView；没有网络客户端。仅用户复制操作写剪贴板，不读取剪贴板。 |
| `src/windows.rs` / `windows_process.rs` | 当前用户 SID、文件所有权、系统状态与精确程序/MSIX 包族身份 | 不枚举 Credential Manager 密码；只写剪贴板。参数和创建时间不序列化；结束时重新核验 SID、程序和 live handle，浏览器仅按完整资料目录关闭。 |
| `src/cleaner*.rs` | Claude 白名单元数据与待清理配置；界面接收预览和脱敏结果 | 快照、当前用户所有权、规范路径、链接与进程状态核验；用户确认后先压缩加密暂存并完整验收，再从工作区移除或替换；失败恢复，崩溃保留恢复状态。个人资产的保留由用户选择；桌面范围限定会话/登录子目录与选定配置，未知个人文件不纳入。Linux 只按精确 XDG 白名单补充缓存，不扩大文件夹清理范围。 |
| `src/browser/config.rs` | 本机环境与用于出口探测的系统代理 | `Machine.system_proxy` 使用 `skip_serializing`，代理凭据不进入 WebView、浏览器回环 JSON 或 UI 日志；对应回归验证。 |
| `src/browser/server.rs` | 匿名环境观测在 A/B 之间交换 | 仅随机令牌 `127.0.0.1` 会话，限制请求大小与资源根目录；只读回报接口返回同会话的匿名环境观测/接收时间，不提供文件写入、命令执行或远程监听。 |
| `src/browser/network.rs` / 前端出口探测 | 向 `ipwho.is`、`ipapi.co` 请求出口信息 | 外部服务会看到请求出口 IP；不发送本地文件、账号、密钥或浏览记录。服务失败使用同一路由备用服务，不伪造成功。 |
| `src/network_links.rs` | 固定 VPS/家宽/Skill 公开入口 | 仅白名单地址与供应商配置编译内嵌；应用不选择密钥、不收集家宽资料、不注册 SSH/部署命令。 |
| `skills/ccbaga-network/scripts/network.py` | 用户主动提供的附件、VPS 地址与家宽连接资料 | AI 经标准输入提交配置，验证后保存 Git/Skill 外的 0600 文件；拒绝覆盖和链接路径。配对后临时 PEM 0600，事务结束移除；仅所选 VPS 经 SSH 接收家宽配置，秘密不进入 argv/公开日志。用户交给 AI 的资料可能由其服务提供商处理，不能声称完全不进入模型。 |
| `scripts/claude-cli.sh` | 用户选择的 CLI 卸载/重装 | 明确确认后只修改已识别 CLI 程序；保留配置、会话、技能和项目。重装使用官方安装地址或既有包管理器，并核验实际版本。 |
| `scripts/install-linux.py` | 用户选择的本地构建产物 | 拒绝外部启动器、链接安装父目录和仍运行的 A/B；替换失败回滚，不迁移或读取用户资料。 |

## 状态与授权

- Linux 源码安装器检查整个本安装应用目录下的进程，A 或 B 运行时均拒绝替换其资源；回归验证安装目录保持不变。
- Linux 定位未知保持 `null`，不能显示已关闭或触发绿色通过；不可验证的机器对齐在任何系统修改前停止。
- 官方发布任务只允许 `liseami/CCBaga` 的所有者触发和重跑；PR 和 fork 不触及签名凭据。开发文档不授予官方发布身份。

## 发布与入口边界

- `skills/ccbaga-network/providers.json` 由固定导航编译内嵌，也供独立 Skill 消费，WebView 传供应商编号，不传可任意改写的 URL；现有回归锁住两条原始完整目标地址。
- Linux/Arch 构建任务没有 Apple 或更新私钥；macOS 临时钥匙串只授权 codesign。构建、DMG 工具和更新签名子进程不继承 Apple 凭据，公证工具只接收明确的认证参数。
- RPM 使用标准 rpmbuild 从已构建的非 AppImage /usr 文件树生成，禁用安装钩子和引擎剥离；Linux 内置更新仍禁用，RPM 当前沿用非 AppImage 宿主的 DEB 类型提示；后续启用 Linux 更新必须先补齐 RPM 类型标注。DEB/RPM/AppImage 将浏览器隔离在 libexec，避免 linuxdeploy 将可选 Qt 库当作宿主必需依赖或改写厂商 ELF；解包后仍严格比对引擎字节。所有平台产物验收完成后才创建正式版本。公开产物清单不包含密钥、钥匙串或完整私有配置。

## 本机开发与正式安装

本机 `dev:install` 不读取 Apple/更新私钥，强制临时签名与 debug/custom-protocol。开发浏览器临时签名清除 runtime，避免无 Team ID 的 Framework 被正式库验证拒绝；正式签名仍启用 runtime 与可信时间戳。安装前实际执行 Chromium --version 验证加载。开发安装只能选择仓库的 debug 宿主和本机引擎；拒绝与外部 DMG 路径组合，并核验两个包确为临时签名。正式安装仍要求严格签名和 Gatekeeper。此开发边界不移除下载包隔离、不禁用系统安全机制；用户数据仍沿用同一事务保护。

Windows Skill 私密文件采用用户 SID 独占且保护的 NTFS ACL，写入秘密之前核验；拒绝 junction 和 symlink 父目录。原生 OpenSSH/curl、不依赖 WSL；Job Object 只管理本次子进程树。Windows CLI 卸载和 NSIS 更新不删除用户配置/技能/资料；安装回归只在空白 CI runner 执行。Windows 构建不接触 Apple 凭据或更新私钥，版本签名仅在验收后的独立步骤注入。

## 验证边界

前端、原生、安装边界与独立 Skill 使用可重复的离线回归；公开更新向量另需实际清单与签名归档。Skill 回归使用临时生成密钥和伪配置，不使用用户凭据，不连接 VPS。配置非交互验证、拒绝 Git/Skill 写入与覆盖、秘密标准输入传输、完整目标链接、配对/权限/清理与失败/超时均有可运行回归。各平台构建运行 Skill 与原生验收，Linux 安装包按真实引擎字节检查后才交付。真实 VPS、家宽账号、TUN、桌面权限和第三方浏览器行为须在目标环境验证；未执行的操作不记为通过。视觉验收由项目所有者完成。

目录统计完整遍历白名单目标的元数据，不读取正文、不进入链接目标；不以目录规模或计时截断正常扫描。任何元数据或目录读取失败均显示路径和系统原因，并拒绝生成该目标的删除快照。清理前仍重复比较完整树指纹，变化即拒绝。

## 本地身份保险库

- 身份卡片按用户要求显示本地账号的用户名、邮箱和组织；仅从默认 .claude.json 的 oauthAccount 允许字段读取，限制大小和显示长度，未知字段不序列化。Desktop 检测仅元数据，不读取 Cookie 正文或钥匙串，不联网识别。没有读取到显示信息时明确标注，不把缓存账号信息当成服务端认证结果。

- SQLite 只管理脱敏目录、保留选择和持久恢复状态；大文件和凭据写入 BAGAID01 认证加密容器。压缩使用成熟 tar/gzip，加密使用 ring AES-256-GCM；不是自创密码算法。
- key.bin 与数据库/归档均在受限保险库中，POSIX 私有权限、Windows 当前用户独占 DACL；主密钥未放在 SQLite、安装包或公开仓库。本机同用户或管理员拥有的权限无法被文件格式消除，不能承诺 Claude 永远无法发现保险库。
- 默认 Code/Desktop 登录凭据经用户确认读取，macOS保留系统授权；原生调用无凭据 argv/网络传输。其他自定义配置目录的账号不自动切换。
- 登录资料始终随身份暂存；用户控制其他数据的保留/暂存。只管理本地状态，服务端失效可能要求重新登录。程序卸载/重装保留保险库。
- 原有批量清理 RPC 已移除。身份切换始终先保存并验证归档；独立直接删除命令由 GUI 明确确认，不新增备份，只处理所选范围。删除暂存卡片不修改当前工作区。文件删除不等于磁盘安全擦除。
