# src/
> L2 | 父级: ../CLAUDE.md
界面只管理输入、状态和执行记录；本机权限与 SSH 执行交给原生层。两入口复用 YAML 中英文文案，原始诊断保留到呈现时翻译；系统语言与界面语言独立。
browser.tsx: 默认浏览器状态与「一键设为默认浏览器」（触发系统确认）、指纹与代理配置、Default 资料缓存清理、跟随目标地区的真实观测核验与显式机器对齐；复用 Cromma UI 和活动日志。
browser-model.ts: 工具箱与起始页共享配置、目标地区、机器、出口服务目录、观测接收时间与默认浏览器契约，不接入原生权限。
browser-start.tsx: 实际 navigator/Intl/Permissions 与 HTTPS 出口上报，心跳和回报时间显示本机通讯状态；已测项目全部匹配、回传成功且无错误时显示整页绿背景与大对勾，重测或断连取消成功状态；随机令牌回环服务隔离宿主命令。
browser-network.ts: 按宿主服务目录经浏览器当前路由检测出口，限流/故障切换服务，校验结果并保留失败原因。
browser-network.test.ts: 模拟限流、备用响应与非法出口，验证故障恢复和错误信息，不访问外网。
main.tsx: 单窗口极简侧栏，傻瓜设置置顶，分隔线后依序网络环境、Claude 清理、浏览器环境、电脑环境；按房屋、节点、清理、窗口、齿轮分配图标；全局任务锁控制导航。
cleaner.tsx: 全机/文件夹范围、分类列表与完整预览；确认窗可结束全部已识别的 Claude 进程并重扫，选择按原路径映射后再次确认删除；只提交快照编号；CLI 管理行读取真实安装来源与版本，卸载/重装确认后先结束进程，复用任务锁与活动日志。
cleaner-folder.tsx: 原生拖放与路径输入选择目录；拖入只扫描，返回全机扫描需明确选择。
cleaner-activity.tsx: 清理、CLI 安装与其他事务的单次调用进度通道、实际进度、耗时与默认收起的有界日志；保留原始消息供即时切换语言，不参与修改决策。
cleaner-model.ts: 清理预设、父子目录去重、子项排除、重扫编号映射与规模格式化，供预览和执行共享。
cleaner-model.test.ts: 预设、父子选择隔离与重扫不扩大选择的回归，不调用清理命令。
cleaner-processes.ts: 快捷和高级预览共用的只读进程轮询；外部退出自动更新阻挡状态，不更新文件快照。
system.tsx: 电脑环境页，当前状态与目标草稿分离；时区、语言和定位各自应用；钥匙串解锁与系统授权入口归入本页。
index.css: 系统字体与共享主题入口，删除未使用官网样式与品牌字体资源。
locales/: 双语 YAML 目录及导入类型；见其 CLAUDE.md。
i18n.ts: 共享界面语言订阅与文案格式化；优先精确键，动态原生结果按最具体模板匹配，未知诊断保留原文。
i18n.test.ts: 双语键/插槽一致性、界面文案覆盖、原生错误与语言切换回归；不访问真实设置。
language-switch.tsx: 极简中英文切换；宿主原子持久化成功后更新界面，失败保留原偏好并显示错误。
dialog.tsx: Radix 受控模态、无 Trigger 时的原焦点恢复与读屏标题，ModalShell 关闭按钮支持当前语言、底部操作自动换行。
style.css: 极简侧栏、统一标题/操作/结果层次、系统字体留白、完整预览、CLI 管理、三文件密钥导入与供应商按钮行/按需帮助的响应式布局；首页按钮沿用 Cromma UI 的边缘、内高光、阴影与悬停效果；实测通过时整页绿色与 112px 对勾只作用于浏览器实测入口。
quick-actions.tsx: 傻瓜设置页地区与四个带图标快捷操作；Claude 预览可结束全部进程并重扫再确认，进程状态与高级页共用；复用浏览器/系统/清理命令。
vps.tsx: 网络环境只要求 VPS 地址与完整三文件密钥包；固定 root:22，无密码/Agent/手填路径；家宽 SOCKS5、远端修改确认与订阅展示保持独立。蓝色 VPS / 绿色家宽获取按钮和问号选购指南放标题下；DMIT 指明 Generate SSH Key after order；家宽密码不持久化、设置后清空。
vps-keys.tsx: PEM/PPK/PUB 文件图标占位，原生点选与拖放统一提交路径；缺任一种不允许连接，文件正文与配对只由 Rust 核验。
