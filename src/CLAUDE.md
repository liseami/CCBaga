界面只管理输入、状态和执行记录；本机权限交给原生层；网络页仅提供入口与安装提示词，SSH 执行属于独立 Skill。两入口复用 YAML 中英文文案，原始诊断保留到呈现时翻译；系统语言与界面语言独立。
browser.tsx: 默认浏览器状态与「一键设为默认浏览器」（触发系统确认）、指纹与代理配置、Default 资料缓存清理、跟随目标地区的真实观测核验与显式机器对齐；站点永久删除使用 Alert 警告并默认取消；复用 Cromma UI 和活动日志。
browser-model.ts: 工具箱与起始页共享配置、目标地区、机器、出口服务目录、观测接收时间与默认浏览器契约，不接入原生权限；三平台设备/CPU/版本核验由共用函数保持一致，Windows 必须 Win32。
browser-start.tsx: 实际 navigator/Intl/Permissions 与 HTTPS 出口上报，心跳和回报时间显示本机通讯状态；已测项目全部匹配、回传成功且无错误时显示整页绿背景与大对勾，重测或断连取消成功状态；随机令牌回环服务隔离宿主命令。
browser-network.ts: 按宿主服务目录经浏览器当前路由检测出口，限流/故障切换服务，校验结果并保留失败原因。
browser-network.test.ts: 模拟限流、备用响应与非法出口，验证故障恢复和错误信息，不访问外网。
main.tsx: A 品牌图与 BAGA! 标志取代装饰图标；单窗口极简侧栏按 Laper VerticalNavbar 的 240px 宽/72px Logo 区/40px 行与 14px 字级排布，傻瓜设置置顶，分隔线后依序网络环境、Claude 身份管理、浏览器环境、电脑环境；按房屋、节点、身份盾牌、窗口、齿轮分配图标；全局任务锁控制导航。
identities.tsx: 空身份固定最左、当前账号其次的竖式 196×312 工牌，单排横向卡片，顶部挂孔绿光表示当前身份、无障碍名称保留状态语义；Motion 弹簧滚轮/轻微悬停视差，原生媒体订阅使减弱动态偏好实时停止动画；滚动条/键盘保持原生，无分页或数量截断；卡片直接切换、折叠保留选项、名称、切换/恢复/永久删除 Alert 警告（需勾选确认，默认聚焦取消）；只调用受限原生身份命令，凭据不进 UI。
identity-model.ts: SQLite 受限目录、当前显示字段和保留策略契约，Skills/插件/MCP/个人设置/项目记录/历史/缓存逐项由用户选择。
claude-cli-panel.tsx: 身份页内的 CLI 维护；复用安全进程结束和官方卸载/重装，保护保险库与个人资料。
cleaner-activity.tsx: 身份暂存/切换/直接删除、CLI 安装与其他事务的单次调用进度通道、实际进度、耗时与默认收起的有界日志；保留原始消息供即时切换语言，不参与修改决策。
cleaner-model.ts: 清理预设、父子目录去重、子项排除、重扫编号映射与规模格式化，供预览和执行共享。
cleaner-model.test.ts: 预设、父子选择隔离与重扫不扩大选择的回归，不调用清理命令。
system.tsx: 电脑环境页，当前状态与目标草稿分离；时区、语言和定位各自应用；钥匙串解锁与系统授权入口归入本页；Windows 隐藏不适用的钥匙串按钮和辅助功能要求，使用实际系统授权状态。
index.css: 系统字体与中性黑白基础主题入口，共享控件扫描；Landing 的几何与纹理归 style.css。
locales/: 双语 YAML 目录及导入类型；见其 CLAUDE.md。
i18n.ts: 共享界面语言订阅与文案格式化；优先精确键，动态原生结果按最具体模板匹配，未知诊断保留原文。
i18n.test.ts: 双语键/插槽一致性、界面文案覆盖、原生错误与语言切换回归；不访问真实设置。
app-update.tsx: 侧栏静默/手动版本检查、实际字节进度、签名下载安装与重启失败重试；锁住其他任务，macOS 只更新 A，B 使用完整 DMG；Windows 先正常退出 B，再以签名 NSIS 更新两程序。
language-switch.tsx: 极简中英文切换；宿主原子持久化成功后更新界面，失败保留原偏好并显示错误。
dialog.tsx: Radix Dialog/AlertDialog 受控模态，警告阻止遮罩误关闭且默认聚焦取消；无 Trigger 时的原焦点恢复与读屏标题/描述，ModalShell 关闭按钮支持当前语言、底部操作自动换行。
style.css: 最新 Laper Landing 的四周 16px 外框/隔带（顶端与系统标题行分开）、侧栏完整四边细线、6px 斜纹节距与 7px 点阵标题，颜色统一墨黑；全页满宽细线内容面替代松散圆角卡片，侧栏保留图标与中性选中质感；纹理静态 CSS，竖式工牌有当前状态绿色发光挂孔、叠层边缘/高光/厚度阴影，单排原生横向滚动且空身份白底；模态沿用 Cromma 控件；实测通过页面仍独立整页绿底与 112px 对勾。
quick-actions.tsx: 标题为「傻瓜設定」的地区与四个快捷操作；Claude 快捷入口打开身份页的空身份确认；复用浏览器/系统命令，身份正文不进入快捷区。
vps.tsx: 网络三步为一体细线网格与 01/02/03 标签，VPS 蓝色服务器按钮、家宽绿色住宅按钮及右侧问号/精简规格表，无箭头；斜纹隔带后的 Skill 区为通用/Codex/Cursor/OpenCode/Copilot 五项 LobeHub 图标分段、仅安装与运行的双语提示词与一键复制，复制状态随语言/工具失效；不收集凭据或执行部署。
network-skill.ts: npm skills 标准安装命令/agent 标识与运行入口，通用项由 AI 选当前 agent，关闭安装统计；双语提示词仅安装/运行，具体网络协议归 Skill。
network-skill.test.ts: 五项工具顺序、安装命令/调用符与完整双语复制内容回归，拒绝混入网络流程描述。
